# Anti-Piracy Policy

tonEMU is an emulator frontend. It is built to play games and use system files that **you legally own**.

## What tonEMU does not do

- tonEMU does **not** include, bundle or download ROMs, games, BIOS files, firmware or encryption keys.
- tonEMU does **not** link to, host or search for pirated content.
- tonEMU does **not** contain any tool to bypass copy protection or DRM.
- The only things the app downloads are box art and cheat files from public libretro repositories on GitHub.

## What we ask of users

- Only play games you legally own.
- Dump BIOS and firmware files yourself from hardware you own (for example the Nintendo DS `bios7.bin`, `bios9.bin` and `firmware.bin`, or a PlayStation BIOS).
- Follow the copyright laws where you live.

## What is not allowed in this project

Please do not do any of the following in issues, pull requests, discussions, comments, reviews, wikis or any other tonEMU channel:

- Ask for, offer, link to or share ROMs, games, BIOS files, firmware, keys or "where to download" information.
- Attach save files or screenshots that make it clear a game is pirated.
- Submit code whose main purpose is to circumvent copy protection or to download pirated content.

Such posts will be **removed without warning**, and repeat offenders will be blocked from the project. If you are unsure whether something is allowed, ask first.

## Reporting piracy

If you see pirated content, or a request for it, in a tonEMU channel, report it to **jedplatforms@gmail.com** with a link. We will remove it as soon as we can.

If you are a rights holder and believe something in this repository infringes your rights, email the same address with the details and we will respond promptly.
